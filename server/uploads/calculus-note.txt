【第一部分：极限与连续】
1. 等价无穷小代换核心公式：
   当 x -> 0 时：
   - sin(x) ~ x,  tan(x) ~ x,  arcsin(x) ~ x,  arctan(x) ~ x
   - ln(1+x) ~ x,  e^x - 1 ~ x,  a^x - 1 ~ x ln(a)
   - 1 - cos(x) ~ 1/2 x^2
   - (1+x)^a - 1 ~ ax
2. 洛必达法则适用条件：
   - 必须是 0/0 或 inf/inf 型。
   - 导数比值的极限存在（或为无穷大）。
   - 注意：每次求导前必须化简！能代换等价无穷小的优先代换。

------------------------------------------------------------------------
【第二部分：中值定理证明题】
1. 罗尔定理 (Rolle)：若 f(x) 在 [a,b] 连续，(a,b] 可导，f(a)=f(b)，则存在 c 属于 (a,b)，使 f'(c)=0。
2. 拉格朗日中值定理：f(b) - f(a) = f'(c)(b-a)。
3. 辅助函数构造法：
   - 若要证明 f'(x) + g'(x) = 0 形式，构造 F(x) = f(x) + g(x)。
   - 若要证明 f'(x) + f(x) = 0 形式，构造 F(x) = e^x * f(x)。
   - 若要证明 x*f'(x) + n*f(x) = 0 形式，构造 F(x) = x^n * f(x)。

------------------------------------------------------------------------
【第三部分：积分法与应用】
1. 第一换元法（凑微分）：
   ∫ f(g(x))g'(x)dx = ∫ f(g(x))d(g(x)) = F(g(x)) + C。
2. 第二换元法：
   对于含有根号 √(a^2 - x^2)，令 x = a*sin(t)；
   对于含有根号 √(a^2 + x^2)，令 x = a*tan(t)。
3. 分部积分法公式：
   ∫ u dv = uv - ∫ v du。
   优先级排序：反三角 > 对数 > 幂函数 > 指数 > 三角。
