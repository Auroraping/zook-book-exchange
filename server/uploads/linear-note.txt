【第一章：矩阵与其初等变换】
1. 矩阵乘法注意点：
   - 不满足交换律：AB != BA（一般情况下）。
   - 满足结合律和分配律：A(BC) = (AB)C, A(B+C) = AB + AC。
   - 若 AB = 0，不能得出 A = 0 或 B = 0。
2. 转置与伴随矩阵公式：
   - (AB)^T = B^T * A^T
   - (AB)^-1 = B^-1 * A^-1
   - A* = |A| * A^-1 （当 A 可逆时）
   - (A*)^T = (A^T)*,  |A*| = |A|^(n-1)

------------------------------------------------------------------------
【第二章：矩阵的秩 (Rank)】
1. 秩的核心性质：
   - r(A) = r(A^T)
   - r(k A) = r(A) (k != 0)
   - r(A + B) <= r(A) + r(B)
   - r(AB) <= min(r(A), r(B))
2. 矩阵乘法满秩消去律：
   - 若 A 可逆，则 r(AB) = r(B)，r(CA) = r(C)。
3. 满秩矩阵与可逆等价：
   - n 阶方阵 A 可逆 <=> r(A) = n <=> |A| != 0 <=> Ax = 0 仅有零解。

------------------------------------------------------------------------
【第三章：线性方程组的解】
1. 齐次线性方程组 Ax = 0：
   - 必有零解。
   - 当 r(A) = n 时，仅有零解。
   - 当 r(A) < n 时，有非零解，且其基础解系中含有 n - r(A) 个线性无关的解向量。
2. 非齐次线性方程组 Ax = b：
   - 无解 <=> r(A) < r(A|b) （系数矩阵的秩小于增广矩阵的秩）。
   - 唯一解 <=> r(A) = r(A|b) = n。
   - 无穷多解 <=> r(A) = r(A|b) < n。
   - 通解结构：X = k1*a1 + k2*a2 + ... + c，其中 k_i*a_i 为齐次通解，c 为非齐次特解。
