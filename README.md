# 求书 (ZJU Used Book Platform)

**“求书” —— 面向浙江大学师生的校园二手教材交易与学术资源服务平台**

本项目旨在通过“互联网+学术流通”的模式，解决高校学生教材购买成本高、资源匹配效率低、知识沉淀难等痛点。核心价值在于：**降低教材成本、提升匹配效率、促进知识流通**。

---

## 📂 目录结构说明

本项目采用分层化的目录管理规范，各模块职责定义如下：

- **`client/` (前端系统)**
  - 基于 **Vite + React + Tailwind CSS** 开发的高保真前端原型。
  - 核心包含 13 个业务页面，完整实现了从“课表导入”到“AI 教材必要性评分”再到“IM 谈价”的业务闭环。
- **`server/` (后端系统)**
  - 后续后端 API 服务预留目录。计划支持校园认证、智能搜索与数据持久化逻辑。
- **`prototype/` (原型设计)**
  - 最初的 UI/UX 设计方案与静态演示原型。

---

## ✨ 核心特色主线

1. **校园教材交易**：针对浙大校区分布（紫金港、玉泉、西溪等）提供同校区面交优先策略。
2. **课表绑定推荐**：支持教务系统课表对接，实现“一键购齐”专业所需教材。
3. **AI 教材必要性评分**：通过 AI 大数据分析历年评价，为学弟学妹提供“该书是否必买”的避坑指南。
4. **共享笔记社区**：不仅卖书，还卖知识，集成学霸笔记与期末复习资料。

## 🛠️ 快速上手

### 预览前端原型
1. 进入 `client` 目录：
   ```powershell
   cd client
   ```
2. 安装依赖：
   ```powershell
   npm install
   ```
3. 启动开发服务器：
   ```powershell
   npm run dev
   ```
4. 在浏览器中访问 `http://localhost:5173`。
